# DesignLab Editorial Agency System

Visual direction:
- work first
- oversized editorial typography
- compact vertical rhythm
- low-card / low-chrome interface
- blue-forward DesignLab identity
- clear client proof
- simple service categories
- restrained motion

The homepage does not duplicate another agency's copy or exact layout. It uses
the structural principles of modern editorial agency websites and DesignLab's
own content and data.

Testimonials remain hidden until verified client feedback is added to
`testimonials.js`.
